# Great Expectations Airflow Provider

A set of Airflow operators for [Great Expectations](https://greatexpectations.io/), a framework for describing data using expressive tests and then validating that the data meets test criteria.

## Compatibility

The provider supports Apache Airflow 2.11 and later 3.x releases (below 4), Python 3.11 and later, and Great Expectations 1.23.2 or later 1.x releases (1.24.0 or later on Python 3.14).
Install it as Airflow recommends: pin `apache-airflow==<your version>` in the same command, or use Airflow's constraints file. Some Airflow releases require the constraints file.
If you run Airflow 2.10 or older, or Python 3.10, stay on provider 1.0.0.
See the [compatibility page](https://great-expectations.github.io/airflow-provider-great-expectations/latest/compatibility/) for the tested versions, the install steps and the support policy.
